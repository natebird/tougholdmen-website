Notes

  • No shop or gear in these prototypes, per launch plan.
  • Fonts are free stand-ins: League Gothic for Trade Gothic (headers, caps) and Figtree for Gotham (body). License web versions before launch.
  • Events marked “Sample” are placeholders. Join forms open an email until a form service is chosen.
  • Firecracker is used with dark text, since light text on it is low-contrast.
  • The guide prints Lawn as #614B79, which looks like swapped values; #61794B is used.
